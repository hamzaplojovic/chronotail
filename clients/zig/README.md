# Zig client

Zig integrates directly through the public facade in
[`src/chronotail.zig`](../../src/chronotail.zig). It does not cross the C ABI
and retains compile-time specialization for production files and simulation.

Follow the [Zig guide and API reference](../../docs/clients/zig.md) for writer,
reader, cursor, aggregate, verification, and migration examples.
